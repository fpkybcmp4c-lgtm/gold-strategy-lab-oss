## 原系统只读审计与隔离

审计确认现有界面为 React / TypeScript，使用 Vinext 托管运行、D1 SQLite 风格数据库和 R2 图片存储。数据结构来自源码迁移及仓储 SQL，涉及每日记录、草稿、设置、交易、图片元数据、修改历史、旧来源备份和机会记录；没有读取或导出生产数据库行。

独立版保留现有界面与业务仓储，增加本地 SQLite/R2 兼容接口，使用标准 Next.js 单进程服务。计算、交易生命周期、G1、G1 统计、VNext 风险及统计、账本、资产规则与合约规格这 9 个核心文件，在初始独立版与只读取得的源文件逐字节一致；当前安全修订对其中的输入校验兼容性和集合上限作了上述修改。其他业务文件只做初始化配置与来源地址脱敏，未更改计算函数或模型定义。

原站点在工作前后均为同一已发布版本，域名、更新时间及访问策略完全一致；所有者独享、外部访客数为零。没有执行生产写入、部署、迁移、访问变更或源码推送。只读源码工作副本无修改。

## 修复与已知限制

- 修正标准 Next.js 路由参数类型兼容问题；修正本地自定义服务内部地址导致正常同源保存被误拒的问题。两者仅影响独立版部署适配。
- 首次使用应配置验证日期、本金、合约与费用。缺失成本或合约信息继续显示未知，不虚构结果。
- 交易删除沿用回收站方式，可恢复；日记录可删除。完整恢复使用停机备份，JSON 导出不含图片原图。
- 个人单用户本机服务，无公共认证/注册。远程独立服务器通过 SSH 隧道访问，不应直接开放端口。
- 扫描规则不能证明不存在所有形式的敏感信息；每次新增样本、图片和依赖都需复核。源仓库采用 MIT，依赖遵守各自许可，详见第三方授权说明。
- 浏览器仅检查代表性流程，不代表所有页面、所有屏幕尺寸或所有浏览器均完成手工回归。运行时检查及静态审查未见连接原私人站点；未执行操作系统级网络抓包或完整渗透测试。
- 后续跨平台验证优先补齐 Apple Silicon 与 Safari，并在使用者自行安装的操作系统上完成无缓存人工安装和恢复演练；macOS 15 Intel 的云端完整验收已完成。
